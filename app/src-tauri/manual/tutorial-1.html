Tutorial 1: a teaching room

Upstream I-Simpa's first tutorial, done in Night Mode. The manual · Tutorial 2 · Tutorial 3

This is upstream I-Simpa's tutorial Study of a teaching room (Docs/tutorial_teaching_room.rst in upstream's source), on the project it ships, tutorial_1.proj. Upstream's text builds the room step by step; the project Night Mode opens is that text's end state, so here you check what is set, run both solvers and read the results.

In Night Mode

  1. Help › Tutorial 1: a teaching room, or its card on the start page, opens your own copy in Documents\Night Mode\Examples.
  2. Look through the steps: Geometry shows the model check passed; Materials the three groups; Sources & receivers the source and the two receivers.
  3. Simulate: choose TCR and run (F5). Then choose SPPS and run again (rst:101-117).
  4. Results, the TCR run: the Acoustics tab's Receiver levels card gives each receiver's direct level and its total by Sabine and by Eyring (upstream's punctual receiver window, rst:139), and Sabine / Eyring gives the room's reverberation time, diffuse level and absorption area (upstream's Main results, rst:143).
  5. Results, the SPPS run: the Receivers card gives the room-acoustic parameters at each receiver, computed for you (upstream's Calculate acoustics parameters, rst:151-153); Open response shows the energy response; the Map card draws the floor's sound map, cumulated or over a time window (upstream's animations, rst:155-164).

What upstream expects

The tutorial's text names the results to look at but gives no value for any of them (rst:119-170), and the project ships without its results (the folder holds the project and a screenshot of the room). So there is no number of upstream's to compare a run with.

On this build

Both runs end OK with nothing on the solvers' error output, and their results pass the app's check, so the values are shown. Every result the text names has its place here, with two differences:

  • Upstream's maps of acoustic parameters on the surface receiver (rst:170) are not in this version; the map shows the sound level.
  • Values that ISO 3382-1 defines per source and receiver are computed by the app itself, so there is no Calculate acoustics parameters step to run.
