What Night Mode is

Night Mode is a graphical interface for room-acoustics simulation. It runs the solvers of I-Simpa, the open-source project of Université Gustave Eiffel: SPPS, which traces sound particles through the room, and TCR, the classical theory of reverberation (Sabine and Eyring). The solvers are built from upstream I-Simpa's source with this repository's patches; the interface is new and is not upstream's. A third solver, SPPS on the GPU, is this repository's own port of SPPS to NVIDIA graphics cards.

You give the app a closed room model, a material for every surface, sources and receivers. It meshes the room, runs the solver in the background and shows the results that pass its checks.

Values are shown only when they pass a check. Each run's results are checked when it ends. A value the check does not pass is not shown: its place says REFUSED and why. The results are a simulation with I-Simpa's solvers; they are not compared with measurements of real rooms.

Starting a project

With no project open, the window shows Start with a room:

  • Examples: rooms that are ready to run (I-Simpa's Elmia hall and industrial hall, and four rooms of the BRAS benchmark). Each opens as your own copy in Documents\Night Mode\Examples; the original inside the app is never changed.
  • I-Simpa tutorials: upstream I-Simpa's tutorials 1 to 3, set up as their documents say. Each has its own page: a teaching room, the Elmia hall, an industrial hall, with what upstream expects and what this build gives.
  • New project: an empty project.
  • New box room…: a closed box of the width, length and height you give, with one corner at the origin; its floor, walls and ceiling become three surface groups.
  • Open… (Ctrl+O): a Night Mode project (.simpa), an upstream I-Simpa project (.proj) or a room model (PLY, OBJ, STL).
  • Recent: the last five projects. Open the last project when Night Mode starts makes the app start on the newest one.
  • Unsaved work: if the app did not close properly, the changes it kept (every 30 seconds) are offered here: Restore or Discard.

You can also drop a project or a room model file on the window; it opens as Open… opens it.

Importing a room model

A PLY, OBJ or STL file asks for its Length unit (m, cm, mm, ft, in) and its Up axis (z or y). Nothing is guessed from the model. Under If the check refuses it, choose Leave it or Repair: Repair welds vertices, removes zero-area and repeated faces and turns inward faces out, and writes the repaired model as a new file beside the original, never over it. An upstream .proj carries its own units and opens as an unsaved project.

The window

  • Menu bar: File, Edit, View, Simulate and Help; the project's name, with a dot while it has unsaved changes; the Run button.
  • Step bar: the five steps of the work, Geometry, Materials, Sources & receivers, Simulate and Results, each with a light and a line saying where it stands. The variant switch is at its right.
  • Scene list (left): surfaces, sources, receivers, volumes, fitting zones, air and display, with a filter box. Each source, receiver, plane and zone has an on/off switch and a remove button.
  • 3D view (middle): the room. Its tool bar has Select, Orbit, Place receiver, Place source, Frame model, Present and Turntable; View style chooses how the room is drawn (colour, grey, see-through or wireframe; faces, edges, shading, grids, dimensions). Right-click for the selection menu.
  • Properties panel (right): the current step's panel.
  • Dock (bottom): Acoustics, Console and Runs. Drag its top edge to resize it; double-click to fill the window.
  • Status bar: the app's state, the model (watertight or refused, surfaces, air volume), the active variant and the solvers found.

Each side panel and the dock fold with their chevron. H hides every panel (Present); Esc brings them back.

1. Geometry

The Model check runs on every model: Watertight, Self-intersections, Flipped normals, Open edges and Units. Run is refused until the model passes. The faces involved are highlighted in the 3D view, and the Console has each reason in full. Repair and check again welds vertices closer than a micrometre and writes <name>_repaired.obj beside the original; it never closes holes or separates intersecting faces, which must be fixed in the modelling program.

  • Project: its name and a description, both kept in the project file.
  • Dimensions: length, width, height, air volume, surface, faces, surface groups.
  • Replace model, keep groups…: a new model for the open project. Each face lying within 1 cm of a face of the old model keeps its surface group, and so its material; sources, receivers, materials and settings stay. One undo step.
  • Surface groups: + Group or Edit › Add surface group; rename with F2; Ctrl+click two or more and Merge groups; Del deletes an empty group. To regroup faces, pick them in the 3D view (click a face, double-click for its whole flat surface, Ctrl+click to add, Shift+drag a box) and right-click New group from selection or Move to group.
  • Sound-level planes: + Ear-height plane adds a plane over the whole room; set its height, cell size and corners, or tilt it to any angle. SPPS draws a sound map on it.
  • Fitting zones: + Box zone adds a box of scattering objects (furniture, machinery) with its absorption, mean free path and diffusion law, for all bands or band by band. SPPS on the GPU refuses a project with fitting zones; run it on SPPS.

2. Materials

Pick a surface group in the scene list or in the 3D view and choose its Material. A group still on the import's placeholder is marked UNASSIGNED, and Run stays blocked until every group has a material.

Edit table… opens the library grid: Absorption, Scattering and Transmission, one column per band, and the reflection Law (Specular, Uniform, Lambert, W2, W3, W4, Semi-diffuse), for the whole material or band by band.

  • + Material, + From library (I-Simpa's reference materials) and Delete.
  • Type in a cell and press Enter; numbers take a decimal point. Fill row (Ctrl+R) copies the focused cell across its row.
  • Ctrl+C copies the selection as tab-separated text, exactly as stored; Ctrl+V pastes from a spreadsheet, all or nothing. Values on screen may be rounded; what is stored and copied is not.
  • Transmission: a band with no loss typed does not transmit. Type a loss in dB to switch it on.
  • The law shapes the diffuse part of a reflection only: at scattering 0 it has no effect in SPPS. SPPS has no semi-diffuse case, so a run is refused while a material uses it.
  • Each material has a colour for the 3D view; no solver reads it.

3. Sources & receivers

+ Source adds a source in the middle of the room, + Receiver a receiver; Place in view (or the tools Place source and Place receiver) puts one on a point you click, at the distance from the face you set. Pick one to edit its name, group and position; a receiver also has an orientation and can be turned to face a source. Ctrl+C and Ctrl+V copy and paste a source or receiver.

Emission

  • Spectrum: one of I-Simpa's reference spectra (pink noise, white noise…), an entry of the project's own library, or typed per band.
  • The table gives the sound power in dB re 1 pW per band, its A-weighted value, an attenuation and the resulting Lw, with a Global row. Typing a dB(A) value sets the band's dB.
  • Save to library keeps a spectrum in the project; every source linked to it follows when it changes. Unlink keeps the values and drops the link.
  • Directivity: omni, unidirectional (with its direction) or one of three planes. A measured balloon from an upstream project is shown but cannot be chosen here.

Surface maps: the scene list's + Surface map puts a sound map on surfaces you pick; the Geometry step's sound-level planes are the other kind.

4. Simulate

Choose the Solver: SPPS (particle tracing), TCR (classical theory) or SPPS on the GPU. The GPU entry names the graphics card the app found, or says why it is not available.

Settings

  • Bands: tick the bands to compute, or pick a band preset; Select all and Unselect all. The memory line says what a run's results will take.
  • SPPS: particles per source and band, particles saved for playback, duration, time step, sound-map time step, receiver radius, particle extinction, the method (Energetic or Random), sound maps per band and what they show (intensity or sound level), echograms per source, transmission through walls.
  • Air: temperature, relative humidity, pressure and air absorption.
  • Meshing: preserve walls, scene correction before meshing, and the face size on surface receivers. Mesh now meshes the room on its own, to see what TetGen says before a run.
  • Run time, forecast estimates how long the run takes.

Running

Before running lists what Run needs, each Ready or Blocked: a material on every surface, a watertight model with no self-intersection, sources and receivers inside the room, the air set, results that fit in memory, and the verified build of the solvers. Run quality warns of settings known to make values noisy or refused, with a fix you can apply.

Run (F5, the Run button or Simulate › Run) runs the solver on the saved project, in the background: the app stays usable, and the Console shows the solver's output line by line. Cancel run stops it and records the run as Cancelled. The Job list runs saved projects one after another, each with the solver chosen when it was added.

5. Results

Pick a run in the Runs tab, or finish one. The Results panel gives the verdict: Results verified, Results unverified (the solvers are not the verified build), Results refused (no value is shown, and the panel says why) or The results could not be checked.

The Acoustics tab

The parameters, per receiver and band: SPL, G, EDT, T20, T30, C50, C80, D50, Ts, STI and dB(A), computed to ISO 3382-1 and IEC 60268-16. Each value comes with its range; a value that cannot be given says REFUSED with its reason, and Why values are missing lists each cause once, with a re-run that would fix it when there is one. Cards:

  • Reverberation time, against a room use of DIN 18041.
  • Receivers: the table of parameters by receiver, for one band or all bands summed.
  • Spectrum, Decay, Sabine / Eyring and Absorption by surface group.
  • TCR runs add Receiver levels: direct, total by Sabine, total by Eyring.
  • Source shows one source's share, or all sources summed.

Charts zoom with a drag and go back with a double-click; Axes sets the axes by hand; Image… saves the chart as a PNG. Copy copies a table as tab-separated text, for a spreadsheet.

Response and Listen (SPPS)

Open response shows the energy response per band at a receiver, as a map or a table, with time bins, span and zoom. Listen synthesises an impulse response from the echogram (not a measured or wave-based one), plays it, convolves a dry clip or your own WAV with it, and saves either as WAV.

Maps (SPPS)

The Map card over the 3D view draws the sound map of a surface receiver or a sound-level plane, for one band or all bands together. Options: Difference from baseline (this run minus an earlier run of the project, in dB: blue is quieter, red louder), Cumulative, a time Window, Smooth colour, Contours, a Fixed colour range and the Opacity. Hover a face to read its value. When particles were saved, the same card plays them back step by step, with trails.

The difference map's baseline is the newest other run of the project that started before this one; it cannot be chosen by hand in this version.

The Runs tab

Every run of the project, with its variant, solver, status and check. Select one to see its particle loss per band, its solver and mesh, its warnings and its folder. Give it a Label, Open folder in Explorer, or Delete… it to the Recycle Bin (it can be restored from there).

Variants

A variant puts other materials on some surface groups, without copying the project. The variant switch at the right of the step bar has Baseline and your variants: + adds one and makes it active, a double-click renames it. While a variant is active, a material chosen for a group goes into the variant. Each run records its variant.

Files, runs and export

  • Save (Ctrl+S), Save as… (Ctrl+Shift+S) and Save a copy…, which writes the project to another file and leaves this window on its own. New, Open and closing the window ask first when there are unsaved changes.
  • Runs are written under <project folder>\runs\, one folder per run, with the solver's input and output, its console text and the check's record.
  • File › Export view as PNG… (the 3D view with the map's legend), Export parameters as CSV… and as JSON… (the Acoustics tab's parameters with their ranges or refusals).
  • Undo (Ctrl+Z) and Redo (Ctrl+Y) step through the edits of the project.

Help

The Help menu opens, in your browser: this manual (User manual; the app carries it and needs no network), upstream I-Simpa's online user guide (written for upstream's own interface; its chapters on SPPS and TCR describe the solvers this app runs), upstream I-Simpa's website, and this app's source code. Tutorial 1 to 3 open one of upstream's tutorials: its project as your own copy, and its page. About Night Mode gives this build's version and commit, the solvers' build and the licences of everything the app carries, with the GPL-3.0 and the third-party notices in full.

Not in this version

  • The Model and Results menus, the command palette (Ctrl K), the section view, the section plane and the measure tool: shown, disabled.
  • Choosing a difference map's baseline by hand, or cumulating a difference; pausing a run.
  • A variant that changes one of several groups an upstream project gave one material: change that group's own material instead.
  • Naming a volume or making it a fitting zone from the scene list; choosing a measured directivity balloon.
  • Upstream's embedded Python console and scripts, preferences, languages other than English and an update check.
