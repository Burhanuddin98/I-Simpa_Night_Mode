## 9. GPU-port hazards
1. Bit-exact RNG: boost lagged_fibonacci607 is one global serial stream with variable draws per particle (1 per air-abs step in random mode, 1-2 per hit, unbounded rejection loops). GPU port will be statistically, not bitwise, equal. Validate on band-integrated echograms.
2. Float vs double: geometry (position, direction, t, EPSILON 1e-6 tests) is float; particle energy and point-receiver sums are double; surface and cut-plane cells are float upstream. Atomic-add order changes last bits; use double accumulators or compare with tolerances.
3. Walk semantics: tetra changes only at collisions; free-translation segments are tested against the receiver list of the START tetra; first face hit in order 0..3, not nearest t; collision legs inside a step share pasCourant and the elapsedTime budget.
4. Surface-receiver add runs on every scene-face hit including pass-through faces, before absorption, and flips the shared scene face normal IN PLACE (reportmanager.cpp:264 and :278 bind a vec3 reference to face_scene normal). Later reflection reads the same normal, so the flip persists. Reproduce or fix on purpose.
5. Transmission children are FIFO after their parent; matters only for RNG order. Random mode: absorption draw, then transmission draw only when conditions hold; diffusion==1 draws nothing.
6. Special cases: LOST (no exit face or NULL neighbour), LOOP after 1000 sub-iterations, direct_calc kills at first hit, delay start step, stratified z != -1 re-aiming each step, seed nonzero forces single thread.
7. Patch 0001 changes only the surface and cut bin index (pasCourant/ratio); a GPU port binning at pasCourant must do the same integer division.
