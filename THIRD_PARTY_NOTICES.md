# Third-party notices

The notices for everything I-Simpa Night Mode carries of other people's work, with each licence text in full,
are in one file:

**[`app/src-tauri/about/THIRD-PARTY-NOTICES.txt`](app/src-tauri/about/THIRD-PARTY-NOTICES.txt)**

It covers the I-Simpa solvers and the libraries they are built with, TetGen, SPPS on the GPU and TinyXML-2,
the Visual C++ runtime, NSIS, the fonts, the example rooms and the Listen clips, every Rust crate compiled
into `app.exe` and every JavaScript package in the interface.

That file is the only copy kept in the repository. It is generated by `tools/devtools/third_party_notices.py`
from `cargo metadata`, `app/node_modules` and a hand-written list of the parts no package manager lists; do not
edit it by hand. `python tools/devtools/third_party_notices.py --check` fails when it is stale, and every
installer build runs that check. The installer ships it as `THIRD-PARTY-NOTICES.txt` beside `app.exe`, and
Help › About Night Mode shows it.

[`third_party/tetgen-1.5.0/LICENSE`](third_party/tetgen-1.5.0/LICENSE).
