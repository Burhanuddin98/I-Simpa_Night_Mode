## Traps already paid for

- **Keep the Rust toolchain off B:.** It is at `%USERPROFILE%\.rustup` and `.cargo`. On exFAT,
  rustup fails with *"could not create link … Incorrect function"* and then reports
  *"not installable"*. Cargo builds on B: without trouble.
- **This tool process's `PATH` does not include cargo,** because it started before the install.
  Prefix commands with `$env:Path = "$env:USERPROFILE\.cargo\bin;$env:Path"` and set
  `RUSTUP_HOME` and `CARGO_HOME` explicitly.
- **Windows PowerShell 5.1 turns a native program's stderr into a terminating error** under
  `ErrorActionPreference=Stop`. Gates call such programs through `cmd /c` instead.
- **`gh` is not logged in.** The GitHub API is anonymous here, limited to 60 requests an hour.
- **`"$var:"` inside a PowerShell string is a parse error.** It reads as a drive variable. Write
  `"${var}: ..."`. This was hit four times this session.
- **Patching `.ps1` files from Python heredocs mangles backslashes:** `\t`, `\f` and `\r` became
  control characters. Build paths with `chr(92)`, then scan the file for control characters.
- **An interrupt kills a running workflow silently.** The notification looks harmless. After any
  interrupt, check the agents' last-write times under
  `~/.claude/projects/<cwd>/<session>/subagents/workflows/<run>/`.
- **Launch a workflow `scriptPath` from inside the repo** (for example `target\workflows\`), with
  LF line endings. The session folder path and CRLF are refused.
- **Agents in Git Bash can mangle `CARGO_TARGET_DIR` backslashes.** A 5 GB
  `targetagentstauri-shell\` and a `nul` file landed in the repo root and were removed.
  `.claude/` (agent memory) is gitignored.
- **Nothing goes on D:.** It holds Michael's datasets.
